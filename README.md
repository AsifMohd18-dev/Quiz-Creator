# Quiz-Creator

- A simple quiz maker with a user-friendly interface developed using HTML, CSS, and JavaScript
- Create up to 20 multiple-choice questions, each with four possible answers and quiz anyone using your device.
- Uses JavaScript logic to manage questions, track user progress and calculate their score.
- Calculates the user's final score as a percentage and displays a personalized completion message based on their performance.
- Designed with a responsive user interface for compatibility across devices, including desktop and mobile.

# How to Use?
1. Upload folders/files to code editor.
2. Run `npm install` in the terminal.
3. Run `npm run dev` in the terminal.
